Métricas Teóricas y Comparativa

Comprende el sustento algebraico de cada técnica: descomposición en valores propios, cociente de Rayleigh y análisis ANOVA.

1. PCA (Principal Component Analysis)

No Supervisado

Encuentra una base ortonormal que maximiza la varianza proyectada mediante la diagonalización de la matriz de covarianza muestral Σ.

Ecuación Característica:
Σ · v_i = λ_i · v_i
Donde λ_i representa la varianza retenida por el eigenvector v_i ordenado de mayor a menor.
Espectro de Autovalores (Scree Plot Simulado):

2. LDA (Linear Discriminant Analysis)

Supervisado

Busca un vector directriz w que maximice la dispersión entre clases (S_B) mientras minimiza la dispersión dentro de cada clase (S_W).

Criterio de Fisher (Rayleigh Quotient):
J(w) = (wᵀ S_B w) / (wᵀ S_W w)
Límite de dimensiones máximo: k ≤ número de clases - 1 (para 2 clases, k=1).

3. SelectKBest (ANOVA / Chi²)

Filtro Univariado

A diferencia de PCA o LDA que combinan variables linealmente, SelectKBest preserva las columnas originales intactas según su p-valor estadístico.

Estadístico F-Ratio de Snedecor:
F = MS_between / MS_within
Mantiene interpretabilidad directa al no alterar los nombres ni la escala de las columnas.

Guía de Laboratorio & API Docs

Instrucciones de integración de pipelines de preprocesamiento y extracción espectral en Python/scikit-learn.

pipeline_scikit.py 
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# Pipeline oficial configurado
pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('dim_reduct', PCA(n_components=2))
])

X_reduced = pipeline.fit_transform(X)

Parámetros Soportados en el Pipeline

n_components: int | float Default: 2

Número de componentes ortogonales a retener o porcentaje acumulado de varianza deseada (ej. 0.95).

whiten: bool Default: False

Al activarse, escala los vectores componentes por la raíz del autovalor para tener varianzas unitarias.

svd_solver: {'auto', 'full', 'arpack'} Default: 'auto'

Estrategia de descomposición espectral SVD según la dispersión y tamaño de matriz.
